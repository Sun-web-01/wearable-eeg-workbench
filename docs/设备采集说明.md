# 设备采集说明

这份文档说明怎样把真实或模拟设备接到平台，以及每个采集参数的含义。

## 1. 谁负责连接设备

浏览器只负责显示和操作，不能直接读取蓝牙或 USB。真正连接设备的是运行 NeuroTeam 平台后台的电脑。

```text
设备
  ↓ 蓝牙 / USB / 网络
运行平台的电脑
  ↓ BrainFlow
NeuroTeam 后台
  ↓ HTTP
组员浏览器
```

因此：

- 设备要连接到平台主机，而不是随便连接到某个组员手机；
- 同一时间只允许一个采集任务，避免多人争用硬件；
- 主机休眠、断网或平台进程退出时，采集会中断；
- Docker 通常不能直接访问宿主机蓝牙/USB，真实采集优先在本地主机运行。

## 2. 支持的设备类型

| 类型 | 连接方式 | 适合情况 |
|---|---|---|
| BrainFlow 模拟设备 | 软件模拟 | 没硬件时验证扫描、采集、命名和分析 |
| Muse 2 | 蓝牙 | 常见消费级 4 通道 EEG |
| Muse S | 蓝牙 | 消费级 EEG，能力以固件为准 |
| OpenBCI Cyton | USB 串口/Dongle | 研究型 EEG，常见 8 通道 |
| 自定义 BrainFlow 设备 | 串口、蓝牙、网络 IP | 其他 BrainFlow 支持的设备 |

### 重要：预置设备也会受 BrainFlow 版本影响

平台表中的通道数只是常见配置。实际连接后，以 BrainFlow 返回的硬件描述为准。尤其是 Muse S 的 IMU、不同固件的采样率和通道编号，必须以现场测试为准。

## 3. 使用内置设备采集

1. 给设备充电并开机；
2. 蓝牙设备先完成系统配对，串口设备插好 Dongle；
3. 打开平台“设备采集”；
4. 点击“扫描蓝牙与串口”；
5. 选择设备类型；
6. 填写设备地址或串口；
7. 填写匿名受试者编号；
8. 选择状态标签和计划时长；
9. 点击“开始采集”；
10. 完成后下载 CSV、EDF、元数据，或直接提交分析。

扫描不到设备时，可以先手动填写地址，再检查设备是否被其他程序占用。

## 4. 自定义 BrainFlow 设备

自定义模式不是简单改显示名称，而是把真实设备参数交给 BrainFlow。

需要填写：

| 字段 | 含义 | 示例 |
|---|---|---|
| 自定义设备名称 | 写入记录和文件名的人类可读名称 | `Lab EEG 32ch` |
| BrainFlow Board ID | BrainFlow 内部设备编号 | 以 BrainFlow 官方说明为准 |
| 连接方式 | 地址应该交给哪个连接参数 | 串口、蓝牙、IP、无需地址 |
| 设备地址 | 串口名、蓝牙 MAC/序列号或 IP | `COM3` |

平台会根据连接方式把地址传给 BrainFlow：

- 串口：`serial_port`
- 蓝牙：`mac_address`
- 网络 IP：`ip_address`
- 无需地址：不设置连接地址

开始采集前，平台会先向 BrainFlow 请求该 Board ID 的硬件描述。如果 Board ID 无效，会立即提示，不会创建一个空采集记录。

### 自定义设备名和设备型号不是一回事

“自定义设备名称”是给人看的；真正决定怎样连接硬件的是 Board ID、连接方式和地址。只改名称不会改变硬件协议。

## 5. 模拟设备为什么必须勾选确认

模拟设备产生的是程序合成信号，不是真实受试者数据。勾选“我确认这是模拟数据”是为了防止把演示结果误当成真实实验。

模拟数据可以验证：

- 扫描和采集按钮是否正常；
- CSV、EDF、JSON 能否生成；
- 文件命名是否标准；
- 采集结果能否进入分析队列；
- 报告和下载流程是否完整。

模拟数据不能证明：

- 真实设备连接成功；
- 电极佩戴正确；
- 模型能识别真实脑状态；
- 状态识别或研究结论。

## 6. 受试者编号和状态标签

### 匿名受试者编号

推荐 `S01`、`S02`、`S03`，不要填写真实姓名。

### 状态标签

项目当前只确定研究两类状态，具体类别尚待团队会议决定。采集时先使用：

- `state_a`：状态 A，待团队确定；
- `state_b`：状态 B，待团队确定；
- `other`：过渡、休息或其他不进入两类分类的数据。

平台仍保留旧标签以兼容历史记录，但新采集不应继续随意使用旧的“四状态”名称。正式实验必须记录标签由什么事件产生，以及两类状态的操作步骤和标注依据。

### 运动条件

项目验收要求至少两种可重复运动或干扰条件。每次采集需要在元数据或实验记录中注明当前条件，例如：

- `still`：静坐；
- `head_turn`：按提示转头；
- `upper_limb`：坐姿上肢动作；
- `walking`：受控步行。

条件名称可以调整，但执行步骤、动作频率和持续时间必须固定。

## 7. 文件命名

```text
sub-<匿名受试者>_task-<状态>_acq-<设备>_<YYYYMMDD-HHMMSS>.<扩展名>
```

例如：

```text
sub-s01_task-state_a_acq-muse2_20261028-183000.csv
sub-s01_task-state_a_acq-muse2_20261028-183000.edf
sub-s01_task-state_a_acq-muse2_20261028-183000_metadata.json
```

### CSV

保存统一时间轴、EEG、可选 IMU 和标记，适合平台直接分析。

### EDF

保存 EEG 连续信号，适合 MNE、EEGLAB 等 EEG 软件。某些设备或版本没有 EEG 通道、MNE 导出失败时，EDF 可能缺失，平台会记录警告。

### JSON

记录设备、连接方式、通道、采样率、任务、文件哈希和警告。它不是波形数据，而是这份录制的“身份证”。

## 8. 采集完成后

- “下载”只下载文件；
- “提交分析”会把采集 CSV 送入质量检查；
- 采集记录可以单条、批量或按住 `Shift` 连续选择删除；
- 正在采集的记录不能删除；
- 删除采集记录不会自动删除已经生成的分析任务；
- 删除不可撤销，确认窗口会列出将被清理的文件。

## 9. 常见问题

### 扫描不到 Muse

- 设备是否开机并处于连接状态；
- Windows 蓝牙是否开启；
- 是否被手机或其他软件占用；
- BrainFlow 是否支持当前 Muse 型号和固件。

### 扫描不到 Cyton

- USB Dongle 是否插好；
- 设备管理器是否出现串口；
- 串口号是否填对，例如 `COM3`；
- 是否有其他 EEG 软件占用了串口。

### 有设备但采不到数据

先确认 Board ID 和连接方式是否匹配。自定义设备填错 Board ID 时，平台可能能找到 ID，但实际连接仍可能失败；错误会写入采集状态和元数据。

### 为什么只有 CSV，没有 EDF

可能是设备没有 EEG 通道，或者 MNE 导出失败。查看采集记录里的警告和元数据，不要假设 EDF 一定存在。
