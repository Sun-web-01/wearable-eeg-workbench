# 项目术语表

第一次看项目时，不需要把全部术语记住。遇到看不懂的词，再回来查即可。

## 信号与设备

| 术语 | 通俗解释 |
|---|---|
| EEG | 脑电图/脑电信号。贴在头皮上的电极记录微小电压变化。 |
| IMU | 惯性测量单元，通常包含加速度计和陀螺仪，用来判断头部运动。 |
| 通道 | 一条独立的传感器信号。例如 `eeg_fpz` 是一个 EEG 通道。 |
| Fpz、Pz、C3 | 国际 10—20 系统中常用的电极位置名称。 |
| 加速度 | 物体速度变化的快慢，项目中常用 g 表示。 |
| 陀螺仪 | 测量转动或角速度的传感器。 |
| 采样率 | 每秒记录多少个数据点，单位 Hz。128 Hz 表示每秒 128 个点。 |
| µV | 微伏，脑电电压常用单位，1 µV 等于百万分之一伏。 |
| g | 重力加速度单位，1 g 约等于 9.81 m/s²。 |
| 时间戳 | 某个采样点对应的时刻。`time_s` 是从记录开始算起的秒数。 |
| BrainFlow | 一个统一连接多种 EEG 设备的开源库。平台通过它采集 Muse、OpenBCI 和自定义设备。 |
| Board ID | BrainFlow 给每种硬件定义的数字编号。自定义设备必须填对 Board ID。 |
| LSL | Lab Streaming Layer，用于同步多种实时数据流的协议/工具。 |

## 数据处理

| 术语 | 通俗解释 |
|---|---|
| 滤波 | 保留需要的频率，压低不需要的频率和噪声。 |
| 带通 | 只保留某个频率范围，例如 0.5—45 Hz。 |
| 陷波 | 专门压低一个固定频率，常见是 50 Hz 或 60 Hz 工频干扰。 |
| 重采样 | 把每秒的数据点数量转换成另一个值。 |
| 抗混叠 | 降采样前先去掉过高频率，避免高频伪装成低频。 |
| 工频噪声 | 电网、充电器或电器带来的固定频率干扰。 |
| 平直线 | 信号长时间几乎不变，可能是电极脱落或设备异常。 |
| 削顶 | 信号超过设备记录上限，波形顶部或底部像被削平。 |
| 运动伪迹 | 头动、咬牙、眨眼或电极拉扯造成的非脑电干扰。 |
| Artifact | “伪迹”的英文，指不是目标脑活动本身的干扰。 |
| ICA | 独立成分分析，一种分离部分伪迹和脑电成分的方法。当前不是主流程。 |
| RMS | 均方根，对信号整体幅度的一种概括。适合同设备、同通道比较。 |
| FFT | 快速傅里叶变换，把随时间变化的波形拆成不同频率。 |
| Delta | 约 0.5—4 Hz 的慢波频段。 |
| Theta | 约 4—8 Hz 的频段。 |
| Alpha | 约 8—13 Hz 的频段。 |
| Beta | 约 13—30 Hz 的频段。 |
| Gamma | 约 30 Hz 以上的频段；本项目通常关注到 45 Hz。 |

## 窗口与实验

| 术语 | 通俗解释 |
|---|---|
| Epoch | 从连续信号里截出的一段。项目建议使用 2—4 秒滑动窗口。 |
| Window | 分析窗口，就是一截数据。 |
| Step | 相邻窗口前进多少秒。4 秒窗/2 秒步长表示窗口之间有一半重叠。 |
| Baseline | 基线。这里也可指平台的快速联调后端。 |
| Research | 正式科研处理模式，使用 MNE/SciPy 等工具。 |
| Session | 一次连续记录或一次实验场次。 |
| Subject | 受试者，用 S01、S02 等匿名编号表示。 |
| Run | 同一 session 中的一次具体运行。 |
| Label | 标签，表示某个窗口属于两类状态中的哪一类。具体类别待团队确定。 |
| Annotation | 对事件、状态或异常片段的标注，可以由实验事件、人工判断或外部文件提供。 |
| LOSO | 留一被试：每次用一个人做测试，其他人做训练。 |
| Data leakage | 数据泄漏，测试信息不小心进入训练，会让结果虚高。 |
| Unimodal | 单模态，例如只用 EEG。 |
| Multimodal fusion | 多模态融合，例如同时使用 EEG 和 IMU 特征。 |
| Ablation study | 消融实验，逐项去掉某个模块或输入，检查它对性能的实际贡献。 |
| Motion robustness | 运动鲁棒性，指模型在转头、动作或步行等干扰下还能保持多少性能。 |
| Subject-independent test | 独立受试者测试，测试人员没有参与模型训练和调参。 |
| Subject calibration | 个体化校准，用新受试者的少量允许数据调整模型或阈值。 |
| Macro F1 | 宏平均 F1，先分别计算每个类别的 F1，再取平均，避免只看总体准确率。 |
| Confusion matrix | 混淆矩阵，显示每一类被正确识别和错分到另一类的数量。 |
| Update interval | 实时系统的结果更新间隔。项目目标为不超过 1 秒。 |
| End-to-end latency | 从数据进入系统到给出结果的总延迟，包含哪些步骤必须明确统计口径。 |

## 文件与软件

| 术语 | 通俗解释 |
|---|---|
| CSV | 逗号分隔的纯文本表格，可用 Excel、Pandas 读取。 |
| EDF | 常用的生理信号文件格式，可保存通道、采样率和标注。 |
| JSON | 结构化文本，适合程序读取参数、元数据和报告。 |
| HTML | 浏览器可以直接打开的网页报告。 |
| MNE | 读取和分析 EEG/MEG 的 Python 工具。 |
| SciPy | Python 科学计算库，用于滤波、重采样和信号处理。 |
| Pandas | Python 表格数据处理库。 |
| NumPy | Python 数值数组和矩阵计算库。 |
| FastAPI | 构建团队平台后台 API 的 Python 框架。 |
| API | 程序之间约定好的调用接口。 |
| HTTP | 浏览器和服务器传输网页与数据的基本协议。 |
| Tailscale | 基于 WireGuard 的私有网络工具，让组员像在同一内网一样访问平台。 |
| 127.0.0.1 | 当前电脑自身。每台电脑的 127.0.0.1 都不一样。 |
| 100.x.x.x | Tailscale 常见的私有地址范围。 |
| SHA-256 | 文件指纹。文件内容变化后，指纹也会变化。 |
| 哈希 | 把文件转换成固定长度指纹的过程或结果。 |

## 质量与结论

| 术语 | 通俗解释 |
|---|---|
| Quality score | 平台根据缺失、平直、高频和运动情况计算的筛查分。 |
| A 级 | 规则检查较稳定。不是模型准确率，也不是研究结论。 |
| B 级 | 总体可用，建议人工复核。 |
| C 级 | 质量偏低，需要重点检查。 |
| D 级 | 当前结果不适合直接进入模型。 |
| 可追溯 | 能看到数据从哪里来、用了什么参数、生成了哪些文件。 |
| 可复核 | 人能检查原始信号、质量指标和异常原因。 |
| 可复现 | 同一输入和参数能够重新得到同一处理流程。 |
