# 上传校验与质量检查

这份文档解释：上传文件后平台检查了什么、A—D 等级从哪里来、为什么“格式正确”不等于“数据可靠”。

## 1. 推荐的 CSV 是什么

![推荐 CSV 列名](assets/supported-input-csv.png)

推荐列名：

```text
time_s,eeg_fpz,eeg_pz,acc_x_g,acc_y_g,acc_z_g,state_label
```

- `time_s`：时间，单位秒；
- `eeg_*`：EEG 脑电通道；
- `acc_*_g`：三轴加速度，单位 g；
- `state_label`：两类状态之一的标签，具体类别待团队确定。

截图中的 `rest` 只是旧版占位示例。新采集在状态定稿前应使用 `state_a`、`state_b`，定稿后再替换为正式标签。

图中文字“没有时间列时，在上传界面填入采样率”容易误解。当前实际情况是：

- 网页上传仍要求时间列；
- 命令行处理可通过 `--sample-rate` 自动生成时间轴；
- 网页中的“目标采样率”是处理后的 Hz，不是源数据采样率。

如果 CSV 没有时间列，最稳妥的做法是先补 `time_s`，或者使用命令行模式。

## 2. 三层校验

### 第一层：浏览器预检

文件拖入网页后，浏览器会先检查：

- 扩展名是否为 CSV 或 EDF；
- 是否超过 200 MB；
- CSV 前 64 KB 能否读取表头；
- 是否找到时间列；
- 是否找到 EEG 列；
- 是否识别到 IMU 列。

浏览器预检速度快，只能发现明显问题。它不会读取完整大文件，也不能判断信号是否被污染。

### 第二层：服务端结构读取

上传后会使用 Pandas 或 MNE 读取完整文件，检查：

- 文件是否损坏；
- 是否至少有 2 行有效数据；
- 时间能否解析；
- 是否存在 EEG 通道；
- 时间能否按升序排列；
- 重复时间点是否可去除；
- 采样率是否能估计。

这一步决定文件能不能进入后续处理。

### 第三层：信号质量检查

通过结构检查后，平台会：

1. 重采样到目标采样率；
2. 滤波并处理工频干扰；
3. 检查每个 EEG 通道；
4. 用三轴 IMU 标记运动片段；
5. 按窗口提取频带功率；
6. 计算质量等级并生成报告。

## 3. 各项质量指标是什么意思

| 指标 | 通俗解释 | 只能说明什么 |
|---|---|---|
| 有效比例 | 非空数据占全部数据的比例 | 缺失多不多 |
| 平直比例 | 相邻数值几乎不变的采样占比 | 电极是否可能脱落 |
| 削顶比例 | 大量数值挤在最高/最低端 | 放大器是否可能饱和 |
| 高频噪声 | 45 Hz 以上能量占比较高 | 可能混入肌电、设备噪声 |
| RMS | 信号整体幅度 | 适合同设备、同通道比较 |
| 时间缺口 | 相邻采样间隔异常变长 | 中间可能漏采或掉线 |
| 运动伪迹比例 | IMU 判为剧烈运动的采样占比 | 头动是否可能污染 EEG |
| 保留窗口 | 未被运动门控拒绝的分析窗口 | 真正可进入特征阶段的数据量 |

## 4. A—D 等级怎么来

### 通道等级

每个通道先从 100 分开始，根据以下因素扣分：

- 缺失数据；
- 平直线；
- 高频噪声；
- 峰峰值幅度过于异常。

等级阈值：

- `A`：85 分及以上；
- `B`：70—85 分；
- `C`：55—70 分；
- `D`：低于 55 分。

### 总质量等级

总分会取各 EEG 通道平均分，再根据运动伪迹比例扣分。因此可能出现：

- 每个通道都还可以，但头部运动很多，总分下降；
- 某个通道完全平直，整体被明显拉低；
- 数据很短，滤波器长度大于信号，结果只能用于联调。

### 等级不是准确率

质量分衡量的是“规则看起来是否可靠”，不是模型准确率。B 级数据仍可能经过复核后使用，A 级数据也仍要检查原始波形。

## 5. 演示数据从哪里来

点击“运行演示任务”不会访问外部服务器，也不读取真实受试者数据。

平台使用固定随机种子 `42` 生成：

- 90 秒、128 Hz；
- 2 路 EEG：`eeg_fpz`、`eeg_pz`；
- 3 轴加速度；
- 1.2 Hz 慢波、6 Hz theta、10 Hz alpha 和随机噪声；
- 第 18、47、73 秒三次模拟头动。

演示数据只用于验证软件流程，不能用于证明真实脑状态识别效果。

## 6. 为什么同时支持 CSV 和 EDF

### CSV

- 容易用 Excel 或 Pandas 查看；
- 适合已经对齐时间轴的数据；
- 适合团队内部交换；
- 但单位、设备型号和电极位置容易丢失。

### EDF

- 是 EEG 常用生理信号格式；
- 常带通道、采样率、时间和标注；
- 适合与 MNE、EEGLAB 等工具交换；
- 但文件可读不代表通道名称、单位或电极位置完全正确。

## 7. 哪些结论是可靠的

可靠性较高的规则：

- 文件格式；
- 大小上限；
- 时间缺口；
- 重复时间点；
- 是否存在 EEG/IMU 列；
- EDF 能否被 MNE 读取。

需要人工判断的规则：

- 平直线；
- 削顶；
- 高频噪声；
- 运动伪迹；
- 质量等级；
- 某个窗口是否真的应该排除。

## 8. 新方案下的实验目标

数据质量检查需要服务于项目的正式对照实验：

- 选定两类具有明确操作和标注依据的状态；
- 比较 EEG 单模态与 EEG + IMU 融合；
- 至少比较两种可重复运动条件；
- 按受试者划分训练和测试；
- 完成至少一次严格独立受试者测试；
- 实时系统采用 2—4 秒滑动窗口，更新间隔和处理延迟目标均不超过 1 秒。

数据质量报告至少要说明有效片段比例和剔除原因。模型结果必须基于同一测试集比较，不能对不同方法使用不同清洗规则后再比较。

## 9. 外部项目参考

以下项目用于对照，不代表平台已经完整实现它们的算法：

| 项目 | 用途 |
|---|---|
| [MNE-Python](https://github.com/mne-tools/mne-python) | EEG/MEG 读取、滤波、ICA 和可视化 |
| [Autoreject](https://github.com/autoreject/autoreject) | 自动识别坏试次与坏传感器 |
| [Braindecode](https://github.com/braindecode/braindecode) | 基于 PyTorch 的 EEG 解码 |
| [MOABB](https://github.com/NeuroTechX/moabb) | BCI 数据集和算法统一评测 |
| [YASA](https://github.com/raphaelvallat/yasa) | 睡眠信号分析和事件检测 |

CSDN 教程可以帮助理解概念，但具体参数和 API 应以官方文档和当前安装版本为准。

## 10. 后续可以继续改进

1. 在网页中增加“源数据采样率”字段，并在服务端用它补时间轴；
2. 增加单位一致性、电极蒙太奇和标签覆盖率检查；
3. 试验 Autoreject、ICA 等伪迹处理，并与人工复核对照；
4. 建立固定回归样本，统计规则升级后的误报和漏报；
5. 为不同设备建立经过验证的参数模板。
