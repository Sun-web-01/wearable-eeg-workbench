# 项目方向与验收目标

本文档依据 2026 年 10 月更新后的项目方案整理，是项目范围、实验设计和交付物检查的统一入口。

## 1. 项目名称

> 面向运动干扰的可穿戴脑电多模态融合与跨个体脑状态识别研究

## 2. 已确定的研究方向

项目已从早期的四状态探索收敛为四项技术主线：

1. 选择两类具有明确实验操作和标注依据的脑状态或认知任务状态；
2. 研究 EEG 与 IMU 的多模态融合；
3. 评价运动干扰条件下的识别鲁棒性；
4. 评价模型对未参与训练的新个体的泛化能力，并探索低成本个体化校准。

具体选择哪两类状态尚未最终确定。团队需要根据数据支撑程度共同决定，不能自行假定为“睡眠、疲劳、专注、放松”中的任意两类。

## 3. 两类状态的选择标准

选择状态组合时，至少同时核查以下内容：

| 标准 | 需要回答的问题 |
|---|---|
| 实验操作 | 两种状态分别要求受试者做什么，操作能否重复 |
| 标注依据 | 标签来自事件标记、行为结果、量表还是公开数据集 |
| 公开数据 | 是否有可直接使用或申请使用的数据 |
| 数据规模 | 有多少受试者、session、试次和有效窗口 |
| 数据模态 | 是否同时包含可用的 EEG 和 IMU |
| 标签质量 | 标签边界是否清楚，是否有未知或重叠标签 |
| 时间同步 | EEG、IMU 与事件标记能否对齐 |
| 运动条件 | 是否支持静坐、转头、步行或其他可重复干扰条件 |
| 跨个体评价 | 是否有足够的独立受试者用于训练和测试 |
| 复现成本 | 实验设备、时长、招募和标注成本是否可控 |

建议用同一张评估表比较 2 至 3 个候选状态组合，先确定数据最可靠的组合，再冻结采集范式。

## 4. 数据集核验

现有资料中的 Sleep-EDF、SEED-VIG、DEAP、SEED 等数据可以用于技术预研，但不能自动等同于项目的最终两类状态。

- Sleep-EDF 可用于睡眠相关分期和 EDF 读取验证；
- SEED-VIG 可用于警觉度或疲劳相关方法验证；
- DEAP、SEED 可参考情绪、唤醒度和跨被试建模方法；
- 会议讨论中提到的 Tang 2025 新范式数据集目前只是候选线索。

在把 Tang 2025 纳入正式方案前，必须补齐：

- 论文和数据集的准确名称；
- 官方数据页面与引用；
- 许可证和再分发限制；
- 受试者数量、记录时长和标签粒度；
- EEG、IMU 通道与采样率；
- “即时回忆”任务的具体操作和标签定义；
- 数据划分是否适合跨个体测试。

## 5. 技术路线

```text
两类状态与数据集确定
  ↓
EEG + IMU 同步采集或公开数据整理
  ↓
质量检查、滤波、重采样与运动伪迹处理
  ↓
时域、频域、时频特征提取
  ↓
EEG 单模态基线
  ↓
EEG + IMU 融合模型
  ↓
运动条件对照和消融实验
  ↓
独立受试者测试与个体化校准
  ↓
实时或近实时原型
```

## 6. 必须完成的对照实验

### 单模态与多模态

- EEG 单模态；
- EEG + IMU 融合；
- 其他条件保持不变，只改变输入模态。

### 预处理消融

- 原始或最小处理；
- 基础滤波；
- 滤波 + 运动门控。

### 运动鲁棒性

至少设置两种可重复的运动或干扰条件，例如：

- 静坐；
- 有意转头；
- 坐姿下上肢动作；
- 受控步行。

每种条件都要记录任务设计、执行步骤、设备佩戴方式和样本数量。

### 跨个体测试

至少完成一次严格独立受试者测试：

- 测试受试者不能参加模型训练；
- 测试受试者不能用于调参；
- 数据划分应在建模前冻结；
- 个体化校准数据必须与测试数据明确分开。

## 7. 验收目标

| 项目 | 验收要求 | 证据 |
|---|---|---|
| 数据采集 | 不少于 20 名有效受试者；条件受限时须经导师确认采用较小样本方案 | 匿名编号、实验记录、数据清单 |
| 数据质量 | EEG 与 IMU 有可追溯时间同步信息，记录有效片段比例和剔除原因 | 质量报告、同步检查记录 |
| 状态识别 | 完成两类状态分类，报告准确率、宏平均 F1、混淆矩阵 | 测试集评估报告 |
| 基线比较 | 至少比较 EEG 单模态与 EEG + IMU 融合 | 模型代码、统一测试集对照表 |
| 运动鲁棒性 | 至少两种可重复运动或干扰条件 | 实验方案、分条件结果 |
| 跨个体泛化 | 至少一次严格独立受试者测试 | 数据划分清单、可复现代码 |
| 实时系统 | 实时或近实时显示、状态预测和结果记录 | 可运行程序、演示录像 |
| 实时性能 | 建议 2—4 秒滑动窗口，更新间隔不超过 1 秒，处理延迟目标不超过 1 秒 | 时间戳日志、延迟测试报告 |
| 可复现性 | 固定配置、随机种子、数据划分和模型参数 | 源代码、环境说明、运行文档 |
| 总结材料 | 包含方法、对照实验、误差分析、局限性和改进方向 | 总结报告、答辩材料 |

准确率之外必须同时报告宏平均 F1 和混淆矩阵，避免类别不平衡时只展示一个偏高的总体准确率。

## 8. 当前平台能够支持的环节

当前 NeuroTeam 已支持：

- CSV/EDF 上传和结构检查；
- EEG/IMU 时间轴检查；
- 重采样、滤波和工频处理；
- 通道质量、缺口和平直线检查；
- IMU 运动伪迹门控；
- 窗口频带特征和报告导出；
- BrainFlow 设备采集；
- 数据、参数和结果的团队留痕。

当前尚未完成的正式验收内容：

- 两类状态和实验范式冻结；
- 至少 20 名有效受试者的自采数据；
- EEG 单模态与 EEG + IMU 融合模型；
- LOSO 或严格独立受试者测试；
- 两类以上运动条件的对照实验；
- 个体化校准方法；
- 实时或近实时预测与延迟统计。
