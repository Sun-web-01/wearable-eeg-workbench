# 上传校验与质量检查

## 校验发生在哪里

平台使用三层校验，越靠后检查越深入。

| 层级 | 使用技术 | 检查内容 | 是否能拦截错误 |
|---|---|---|---|
| 浏览器预检 | File API、Blob.text | 扩展名、200 MB 上限、CSV 表头、时间列、EEG/IMU 列 | 可以快速发现明显错误，但不能证明信号质量 |
| 服务端结构校验 | Pandas、MNE、NumPy | 文件读取、通道识别、时间轴、重复时间点、采样率、数据行数 | 可以阻止无法进入分析流程的数据 |
| 信号质量检查 | SciPy、MNE、NumPy | 滤波、重采样、时间缺口、平直线、削顶、高频噪声、IMU 运动伪迹、窗口保留率 | 可以给出质量报告，但仍需要研究人员复核 |

## 系统演示数据从哪里来

“运行演示任务”不会请求外部服务器，也不读取真实受试者数据。它调用 [synthetic.py](../wearable_eeg/synthetic.py) 中的 `generate_demo()`，使用固定随机种子 42 生成：

- 90 秒、128 Hz 的时间序列；
- 2 路模拟 EEG：`eeg_fpz` 和 `eeg_pz`；
- 3 轴模拟加速度：`acc_x_g`、`acc_y_g`、`acc_z_g`；
- 1.2 Hz 慢波、6 Hz theta、10 Hz alpha 和少量随机噪声；
- 第 18、47、73 秒附近的三个模拟头动片段。

这些信号只用于验证“读取—滤波—质量检查—窗口提取—报告导出”流程。它们不对应真实受试者，也不能用于证明脑状态识别准确率。

## CSV 和 EDF 为什么都要支持

CSV 是通用表格格式，适合已经完成时间对齐的自采数据、演示数据和导出结果。它容易用 Excel、Pandas 检查，但文件本身通常不能保证包含设备型号、单位、采样率和电极信息。

EDF 是常见的生理信号格式，可以保存通道、采样率、时间和标注。正式 EEG 数据更适合使用 EDF，但不同设备的通道名称和单位仍需要在报告中核对。

平台不会因为扩展名正确就认定数据有效。CSV 必须能识别时间列和至少一个 EEG 通道；EDF 必须能被 MNE 正确读取。

## 当前质量判断是否可靠

可靠性需要按检查项区分：

- 格式、大小、重复时间点和时间缺口检查属于确定性规则，可靠性较高。
- EDF 读取依赖 MNE，格式兼容性较好，但不能自动证明电极贴附和数据单位完全正确。
- 平直线、削顶、高频能量和运动伪迹属于启发式筛查，适合发现候选异常，不能直接等同于错误。
- A、B、C、D 质量等级是团队内部筛查指标，不是医疗诊断，也不能代替模型准确率或人工判读。
- 运动阈值受设备坐标、佩戴方式和动作幅度影响，正式实验应通过预实验校准。

## GitHub 项目调研

以下星标数量是 2026-10-24 通过 GitHub API 查询的近似值：

| 项目 | 主要用途 | 对本平台的参考 |
|---|---|---|
| [MNE-Python](https://github.com/mne-tools/mne-python) | EEG/MEG 读取、滤波、ICA、事件与可视化 | 继续作为 EDF 和正式预处理基础 |
| [Autoreject](https://github.com/autoreject/autoreject) | 自动识别并修复坏试次、坏传感器 | 后续用于分窗质量筛查，替代简单阈值的一部分 |
| [Braindecode](https://github.com/braindecode/braindecode) | 基于 PyTorch 的 EEG 解码流程 | 用于模型训练、窗口和数据划分联调 |
| [MOABB](https://github.com/NeuroTechX/moabb) | BCI 数据集和算法统一评测 | 参考受试者划分和可复现实验协议 |
| [YASA](https://github.com/raphaelvallat/yasa) | 睡眠信号分析、分期与事件检测 | 用于睡眠数据和伪迹检查的对照 |

这些项目共同采用的核心顺序是：先统一数据和通道信息，再进行滤波、伪迹处理和分段，最后才进入模型。CSDN 教程可以作为入门解释，但版本和参数容易过时，具体实现应以官方仓库和论文为准。

## 下一步改进

1. 为没有时间列的 CSV 增加源采样率输入，避免直接拒绝。
2. 引入 `mne.Annotations` 记录坏段和实验事件。
3. 在正式科研模式中试验 Autoreject 或 ICA，并保留人工复核步骤。
4. 增加单位一致性、通道蒙太奇和事件标签覆盖率检查。
5. 使用固定样本集做回归测试，监控规则升级后的误报率和漏报率。
