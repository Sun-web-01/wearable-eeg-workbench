# 团队共享平台部署与使用

## 1. 先说结论

NeuroTeam 不是把数据上传到互联网云盘，而是由一台持续开机的电脑运行平台。组员通过网页访问同一套账号、任务、采集记录、文件和报告。

当前最推荐：

```text
负责人电脑运行平台
        ↓ Tailscale 私有网络
组员电脑/手机浏览器
```

这样组员不需要和负责人在同一个 Wi-Fi，但必须先加入同一个 Tailscale 网络。

## 2. 安装环境

平台主机需要：

- Windows；
- PowerShell；
- Python 3.11 或更高版本；
- Tailscale（团队远程访问时）。

安装依赖：

```powershell
.\scripts\setup.ps1 -Team
```

这条命令会创建 `.venv`，并安装处理、设备、网页和测试所需依赖。

## 3. 两种启动方式

### 仅本机测试

```powershell
.\scripts\start_team_platform.ps1
```

浏览器打开：

```text
http://127.0.0.1:8000
```

`127.0.0.1` 永远代表“当前这台电脑”，组员打不开。

### 邀请组员访问

1. 负责人安装并登录 Tailscale；
2. 组员安装并登录同一个 Tailscale 网络；
3. 负责人在项目目录运行：

```powershell
.\scripts\start_team_private.ps1
```

4. 脚本会显示类似下面的私有网址：

```text
http://100.x.x.x:8000
```

5. 负责人把该网址私下发给组员。

### 为什么不能发 127.0.0.1

每个人电脑上的 `127.0.0.1` 都指向自己的电脑。组员打开它时，访问的是自己的设备，不是负责人的平台。

### 为什么普通公网打不开

脚本只绑定 Tailscale 私有地址。没有加入团队网络的人无法连接，这是安全边界，不是故障。

## 4. 开机或登录后自动启动

当前主机的 Windows 计划任务名称为：

```text
NeuroTeam Autostart
```

触发条件：

- 当前 Windows 用户登录后自动运行；
- 使用当前用户权限，不需要管理员密码；
- 先等待 Tailscale 进入 `Running`；
- 最多等待 180 秒；
- 如果 8000 端口已经有平台在运行，会直接跳过，不会启动重复服务；
- 计划任务不设置运行时长上限，适合长期运行的小型团队平台。

对应脚本：

```powershell
.\scripts\start_team_autostart.ps1
```

自动启动日志：

```text
team_data/autostart.log
```

可以这样手动触发或检查：

```powershell
Start-ScheduledTask -TaskName "NeuroTeam Autostart"
Get-ScheduledTaskInfo -TaskName "NeuroTeam Autostart"
Get-Content .\team_data\autostart.log -Tail 20
```

如果以后不再需要自动启动：

```powershell
Unregister-ScheduledTask -TaskName "NeuroTeam Autostart" -Confirm
```

## 5. 邀请码怎么用

- 第一个注册账号自动成为管理员；
- 后续组员注册必须填写邀请码；
- 邀请码保存在平台主机的 `team_data/.invite_code`；
- 也可以通过环境变量 `EEG_INVITE_CODE` 指定；
- 不要把邀请码发到公开群聊、GitHub 或截图里。

组员第一次注册成功后，以后只需要用户名和密码登录。

## 6. 账户设置

登录后点击右上角头像或“设置”：

- 可以修改用户名；
- 可以修改密码；
- 修改前需要输入当前密码；
- 用户名支持中文、英文、其他语言、空格、Emoji 和常见符号；
- 用户名长度为 1—32 个字符；
- 用户名不能为空，也不能包含换行或控制字符；
- 团队内用户名必须唯一；
- 修改用户名后，历史任务中显示的提交者名称会一起更新。

密码至少 8 位。当前页面不需要验证码，这是小团队私有网络的简化方案；如果以后开放公网，必须增加 HTTPS、限流和更严格的登录保护。

## 7. 平台页面说明

### 任务工作台

- 上传 CSV/EDF；
- 运行演示任务；
- 查看不同处理参数；
- 查看团队任务；
- 打开报告和下载结果。

### 设备采集

- 扫描蓝牙和串口；
- 使用 Muse、OpenBCI、模拟设备；
- 使用自定义 BrainFlow Board ID；
- 生成 CSV、EDF 和 JSON；
- 把采集结果直接送入分析队列。

### 数据资源

查看公开数据集的用途、许可、样本情况和访问方式。下载或申请前要核对原始来源。

### 团队规范

快速查看窗口、标签、命名、匿名化和训练/测试划分规则。

## 8. 右上角常用按钮

| 按钮 | 作用 |
|---|---|
| 明暗主题切换 | 切换浅色/深色，浏览器会记住选择 |
| 自动同步 | 开关任务列表自动刷新 |
| 头像/设置 | 修改用户名或密码 |
| 退出 | 结束当前登录会话 |

关闭自动同步后，任务不会定期自动刷新，但仍可手动点击“刷新任务”。

## 9. 删除记录

任务和采集记录都支持：

- 单条删除；
- 勾选后批量删除；
- 全选；
- 按住 `Shift` 选择两条之间的连续记录。

删除前会显示确认窗口。点击“保留记录”会立即取消并清空勾选，不会继续保留选中状态。

注意：

- 排队中和处理中的任务不能删除；
- 正在采集的记录不能删除；
- 删除任务会清理数据库记录、上传文件、报告和特征文件；
- 删除采集记录会清理 CSV、EDF 和元数据；
- 删除采集记录不会自动删除已经生成的分析任务；
- 删除不可撤销，重要结果应先备份。

## 10. 数据保存在哪里

```text
team_data/team.db         账号、任务状态和历史
team_data/uploads/        上传的原始文件
team_data/jobs/           报告和特征文件
team_data/recordings/     设备采集文件与元数据
```

这些目录不应提交 Git，也不应同步到公共网盘。

## 11. 备份和恢复

建议每 1—2 周备份：

- `team_data/team.db`；
- 重要任务报告；
- 需要长期保留的特征文件；
- 采集元数据；
- 邀请码和密钥文件。

备份前最好停止平台，避免数据库正在写入时复制出不一致文件。不要只备份报告截图，参数、哈希和原始输入同样重要。

## 12. 默认容量

- 单文件默认最多 200 MB；
- 可用 `EEG_MAX_UPLOAD_MB` 调整；
- `processed.csv` 通常比输入文件大；
- 任务和采集记录太多时，使用删除功能清理无价值联调数据；
- 正式实验原始数据不能因为“占空间”而随意删除。

## 13. 常见问题

### 组员打不开网址

1. Tailscale 是否登录；
2. 是否在同一个 tailnet；
3. 平台主机是否运行 `start_team_private.ps1`；
4. 是否使用 `100.x.x.x` 或 `*.ts.net` 私有地址；
5. 主机是否休眠。

### 能打开登录页但登录失败

- 检查用户名和密码；
- 注意用户名中的空格和符号；
- 如果忘记密码，目前没有邮箱找回机制，需要管理员在可信环境下处理数据库或重新建立账号；
- 不要为了排错把密码发给其他人。

### 邀请码在哪里

查看平台主机上的 `team_data/.invite_code`，或查看启动脚本输出。不要把它提交到 Git。

### 任务一直处理中

- 查看任务事件时间线；
- 检查平台主机是否休眠；
- 检查后台日志；
- 服务重启后，被中断的排队/处理任务会自动重新排队。

### 页面没有自动更新

检查右上角“自动同步”是否关闭。关闭时可以手动点“刷新任务”。

## 14. 公网部署

不建议直接把 `http://公网IP:8000` 暴露给互联网。正式公网部署至少需要：

- HTTPS；
- 复杂邀请码；
- 至少 32 字节随机密钥；
- 防火墙；
- 登录限流；
- 数据备份；
- 隐私和导师/学校审批。

当前 Tailscale 方案适合小团队内部使用，不等同于公开网站或医疗系统。
