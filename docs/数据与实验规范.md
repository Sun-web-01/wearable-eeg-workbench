# 新手数据与实验规范

这份文档回答三个问题：数据应该长什么样、字段是什么意思、怎样才不会把训练集和测试集混在一起。

## 1. 推荐 CSV 格式

![推荐 CSV 列名](assets/supported-input-csv.png)

截图展示的是推荐表头，不是唯一可用表头：

```text
time_s,eeg_fpz,eeg_pz,acc_x_g,acc_y_g,acc_z_g,state_label
```

可以直接复制为示例文件：

```csv
time_s,eeg_fpz,eeg_pz,acc_x_g,acc_y_g,acc_z_g,state_label
0.000,12.4,4.8,0.001,-0.002,1.003,rest
0.008,12.8,5.0,0.002,-0.001,1.002,rest
0.016,12.1,4.6,0.001,-0.002,1.004,rest
```

### 每一列是什么意思

| 列 | 含义 | 单位或取值 |
|---|---|---|
| `time_s` | 从记录开始经过的时间 | 秒 |
| `eeg_fpz` | Fpz 电极位置的脑电电压 | 微伏（µV） |
| `eeg_pz` | Pz 电极位置的脑电电压 | 微伏（µV） |
| `acc_x_g` | 左右方向的加速度 | g |
| `acc_y_g` | 前后方向的加速度 | g |
| `acc_z_g` | 上下方向的加速度 | g |
| `state_label` | 这一时期对应的实验状态 | 文本标签 |

`1 g` 约等于 `9.81 m/s²`。如果设备输出的是原始 ADC 数值，必须先根据设备说明书换算，不能直接标成 `_g`。

### EEG 通道怎么命名

平台优先识别：

- 以 `eeg` 开头的列，例如 `eeg_fpz`、`eeg_ch1`；
- 以 `_eeg` 结尾的列；
- `Fpz`、`Pz`、`C3`、`C4`、`O1`、`O2`、`F3`、`F4` 等常见名称。

只写 `ch1`、`channel_1` 这类名称时，平台无法确认它是 EEG、眼电还是其他信号，可能直接拒绝。

### IMU 怎么命名

列名包含 `acc`、`gyro` 或 `imu` 时会被识别为运动信号。运动伪迹门控最好至少有：

```text
acc_x_g,acc_y_g,acc_z_g
```

只有 EEG 也可以做基础分析，但报告会提示“没有三轴 IMU，无法进行运动伪迹门控”。

### state_label 是不是必填

不是。它是推荐列，用于保留实验状态和以后做模型对照。

- 当前质量报告不会用它自动训练模型；
- 当前 `features.csv` 主要是窗口特征，不自动生成分类标签；
- 如果每一行都重复状态标签，后续可以按时间窗口提取；
- 如果标签按时间段保存，应另附时间区间表，避免把标签和错误的时间段对齐。

## 2. 时间轴的规则

### 有时间列

推荐使用 `time_s`。要求：

- 单位必须一致，不能前一半用秒、后一半用毫秒；
- 时间递增；
- 不重复时间点；重复点会保留第一条；
- 缺失时间点会造成时间缺口，平台会记录最大缺口和估计缺失比例；
- 时间列不是装饰信息，重采样、窗口和运动门控都依赖它。

### 没有时间列

当前网页上传要求存在时间列。可以：

1. 在 Excel/Pandas 中按源采样率补出 `time_s`；
2. 使用命令行并提供 `--sample-rate`；
3. 转成带时间信息的 EDF。

命令行示例：

```powershell
.\.venv\Scripts\python.exe -m wearable_eeg process data/raw/example.csv --sample-rate 128
```

这里 `128` 表示源数据每秒有 128 个采样点，平台会生成 `0, 1/128, 2/128...` 的时间轴。

### 源采样率和目标采样率不同

- **源采样率**：设备原本每秒采集多少点；
- **目标采样率**：处理后希望保留多少点/秒；
- 例如设备是 256 Hz，平台目标可以是 128 Hz；
- 降低采样率前需要抗混叠，正式科研模式使用研究后端完成。

## 3. CSV、EDF 和 Excel 的区别

| 格式 | 本质 | 优点 | 注意事项 |
|---|---|---|---|
| CSV | 纯文本逗号表格 | 通用、容易检查 | 元数据和单位容易丢失 |
| EDF | 生理信号专用格式 | 常带通道、采样率和标注 | 需要 MNE，通道名称仍需核对 |
| XLSX | Excel 工作簿 | 人工编辑方便 | 当前网站不直接支持，应先导出 CSV |

把 Excel 文件后缀改成 `.csv` 不等于完成转换。应在 Excel 中选择“另存为 → CSV UTF-8”。

## 4. 窗口、步长和标签

平台默认使用 4 秒窗口、2 秒步长。意思是：

- 第 1 个窗口覆盖 0—4 秒；
- 第 2 个窗口从 2 秒开始，覆盖 2—6 秒；
- 相邻窗口有一半重叠。

重叠窗口可以增加样本量，但训练集和测试集划分时必须整体按 session/受试者切分，不能让同一段数据分别进入两边。

睡眠分期通常使用 30 秒 epoch；状态识别当前使用 4 秒窗口。不同任务的窗口不能混为一谈。

## 5. 数据泄漏检查

把数据交给模型训练前逐项确认：

- 同一原始 session 是否同时进入训练集和测试集；
- 相邻重叠窗口是否跨集合；
- 标准化参数是否只在训练集上计算；
- 特征选择、阈值和模型选择是否偷看了测试集；
- 标签是否由目标 EEG 自己循环生成；
- 个体校准是否只使用训练阶段允许的数据。

推荐按受试者做 LOSO（留一被试）或 grouped split，而不是随机打乱所有窗口。

## 6. 命名与隐私

推荐目录：

```text
data/raw/sleep_edf_expanded/SC4001E0-PSG.edf
data/processed/sleep_edf_expanded/S001/S01/R001/processed.csv
reports/runs/20261024_sleep_edf_S001_S01_R001_v001/report.json
```

真实姓名、手机号、身份证号、精确住址、原始设备序列号不能进入：

- 文件名；
- Git 提交；
- 截图；
- 公开报告；
- 公共网盘。

受试者使用 `S01`、`S02` 等匿名编号。删除或共享数据前先确认许可，受限健康数据不能随意转发。

## 7. 预处理等级怎么理解

| 等级 | 做了什么 | 适用场景 |
|---|---|---|
| `L0_raw` | 只读取和检查时间轴 | 保留原始证据 |
| `L1_basic` | 重采样、带通、陷波 | 基础可用数据 |
| `L2_quality` | 增加通道、缺口和运动门控 | 当前团队主要流程 |
| `L3_artifact` | ICA/回归等复杂去伪迹实验 | 正式研究，需要人工复核 |

不同等级的数据不能直接混在一起训练。报告和使用说明中必须写清楚版本。

## 8. 每次交付至少留下什么

```text
report.json
report.html
features.csv
processed.csv（按需）
source.sha256 或报告中的文件哈希
run.md
```

`run.md` 用普通话写清楚：这次想验证什么、用了哪些参数、结果怎样、还有哪些问题。
