# 成员 A 执行手册

## 1. 角色边界

成员 A 主责“信号处理与数据”，覆盖研究内容 1—2：

- EEG/IMU 采集方案、同步和时间轴管理；
- 公开数据集获取、许可核对、目录和清单；
- 滤波、重采样、坏段/坏导联评估；
- 睡眠 Hypnogram 与 30 秒 epoch 标签对齐；
- 运动伪迹筛查与去除实验；
- 向成员 B 交付可追溯的特征、窗口和划分信息；
- 向成员 C/D 交付数据导入格式、任务状态和处理结果契约。

成员 A 不应独自包办模型、Web 前后端和实时硬件。最终平台由成员 C/D 主责，A 提供后端处理模块和数据接口。

## 2. 应该搭建什么平台

### 第一层：当前已搭建的离线数据工作台

技术栈：Python + NumPy + Pandas + 本地 HTTP Web UI。

用途：

- 快速查看 CSV 数据能否进入项目；
- 发现缺列、时间缺口、平直线、过高频噪声和运动段；
- 自动生成质量报告、窗口特征和可复现实验产物。

当前平台是验收和联调工具，不是论文最终结果的生产实现。

### 第二层：正式科研处理环境

在现有管线上增加：

- MNE：EDF 读取、事件/anchor、重参考、ICA、坏段处理；
- SciPy：抗混叠重采样、零相位 Butterworth、稳健统计；
- scikit-learn：基线特征与简单分类，用于验证特征是否含信息；
- PyTorch：交给成员 B 建模。

统一环境文件为 `requirements-research.txt`。正式结果必须记录完整环境和参数。

平台通过 `backend=research` 或命令参数 `--backend research` 启用 SciPy 抗混叠重采样和 MNE 零相位 FIR。默认 `baseline` 用于快速联调，不用于最终论文数据。

### 第三层：实时采集与最终产品

- BrainFlow：连接 Muse 2/Muse S 或 OpenBCI；
- Lab Streaming Layer：EEG 与 IMU 多流同步；
- FastAPI：成员 D 维护处理 API；
- React/Vue 或现有 Web 平台：成员 C 负责交互和可视化；
- Docker：成员 C/D 负责部署，不要求成员 A 先搭完整容器平台。

实施顺序必须是：离线数据验收 → 正式预处理 → 特征/模型联调 → 实时流 → 团队 Web 集成。不要在数据质量未稳定时先做实时大屏。

## 4. 实施期（2027 年 1—4 月）

### 1 月

- 建立统一目录：`dataset/subject/session/run`；
- 为 Sleep-EDF 实现 MNE 正式读取和预处理；
- 对每个 session 生成质量报告；
- 检查时间缺口和设备时钟偏移。

验收标准：同一输入重复运行得到一致参数和相同指标。

### 2 月

- 比较原始信号、带通、陷波和 ICA 方案；
- 在 WearBCI 或步态数据上验证 IMU 门控；
- 记录伪迹段比例、保留窗口数和信号质量；
- 向成员 B 提供不同预处理版本，避免只交一份“处理好的数据”。

验收标准：至少形成“未处理 / 基础滤波 / 滤波+运动门控”三组对照。

### 3 月

- 完成 EEG/IMU 时间同步；
- 量化时钟漂移、最大缺口、合并后采样完整性；
- 输出多模态对齐数据和同步报告；
- 与成员 B/C 联调特征和任务接口。

验收标准：任意窗口都能追溯到原始 session、时间范围和预处理版本。

### 4 月

- 分析个体差异对质量指标和窗口数量的影响；
- 配合个体校准实验，提供可靠的被试内/跨被试划分；
- 整理中期检查所需的数据实验图表和限制说明。

验收标准：中期报告能说明数据来源、清洗规则、样本数量、排除标准和误差来源。

## 5. 每个实验的最小交付包

```text
report.json         # 机器可读结果与参数
report.html         # 导师/组会快速审阅
features.csv        # 窗口级特征，交成员 B
processed.csv       # 可复核的中间数据
source.sha256       # 原始文件身份
run.md              # 目的、配置、结论、已知问题
```

`processed.csv` 体积较大，默认不提交 Git；只提交哈希、配置摘要和去标识化后的报告。

## 6. 完成定义

成员 A 的“完成”不是“程序能跑”，而是同时满足：

- 数据来源和许可清楚；
- 参数可复现；
- 缺失、伪迹和质量差的样本可解释；
- 训练/测试划分无同 session 泄漏；
- 下游能直接读取产物；
- 知道结果不能说明什么。
