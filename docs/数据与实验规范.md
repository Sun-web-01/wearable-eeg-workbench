# 数据与实验规范

## CSV 最小格式

```csv
time_s,eeg_fpz,eeg_pz,acc_x_g,acc_y_g,acc_z_g,state_label
0.000,12.4,4.8,0.001,-0.002,1.003,relaxed
0.008,12.8,5.0,0.002,-0.001,1.002,relaxed
```

要求：

- `time_s` 单调递增，单位为秒；
- EEG 列以 `eeg_` 开头，或使用标准通道名；
- IMU 列包含 `acc`/`gyro`；
- 加速度必须注明单位并在文件名或清单中记录；
- 标签与信号分开存放时，另附时间区间表；
- 不允许在同一列混用秒和毫秒。

## 窗口和标签

- 睡眠分期：30 秒 epoch，标签按窗口起点或主导类别，规则必须在 session 清单注明；
- 状态识别：默认 4 秒窗、2 秒步长；试次独立验证时不得跨训练/测试边界切窗；
- 运动伪迹窗口：默认运动采样点比例超过 50% 则拒绝；
- 跨被试实验：先按 subject 分组，再做 LOSO 或 grouped split；
- 任何标准化参数只能从训练集拟合。

## 命名

```text
data/raw/sleep_edf_expanded/SC4001E0-PSG.edf
data/processed/sleep_edf_expanded/S001/S01/R001/processed.csv
reports/runs/20261024_sleep_edf_S001_S01_R001_v001/report.json
```

真实受试者姓名、手机号、身份证号和原始设备序列号不得进入文件名、Git 提交或公开报告。

## 预处理等级

- `L0_raw`: 只做读取、时间轴检查；
- `L1_basic`: 抗混叠、重采样、带通、陷波；
- `L2_quality`: 增加坏段、平直、运动和通道质量门控；
- `L3_artifact`: 增加 ICA/回归/自适应伪迹去除。

训练集版本必须明确预处理等级，不能把不同等级的数据直接混在一起。

## 数据泄漏检查

每次向成员 B 交付前检查：

- 同一原始 session 是否同时出现在训练和测试；
- 重叠窗口是否被分到不同集合；
- 个体校准是否只使用允许的训练段；
- 标准化、特征选择和阈值是否看过测试集；
- 标签事件是否由目标信号本身循环派生。

## 安全检查

- 公开下载数据先核对许可证和访问条款；
- 受限健康数据不转发、不再分发；
- Web 平台默认只监听 `127.0.0.1`，不直接暴露公网；
- 上传文件设大小上限，报告不包含联系方式；
- 对外演示使用匿名编号和合成数据。
