# 实验记录规则

“实验记录”不是只保存一张结果图，而是让别人能够回答：用了什么数据、做了什么、结果怎样、为什么可信。

## 每次实验至少保留五项

1. **输入是什么**：数据集、匿名受试者编号、session、文件 SHA-256。
2. **参数是什么**：目标采样率、带通范围、陷波、窗口长度、运动阈值。
3. **产物在哪里**：`report.json`、`features.csv`、`processed.csv`。
4. **结论是什么**：质量等级、保留窗口、异常通道、能否进入下游。
5. **改了什么**：和上一版相比修改了哪个参数，为什么修改。

## 不要覆盖唯一结果

每次实验使用带日期和版本的目录：

```text
reports/runs/20261024_sleep_edf_sc4001_v001/
reports/runs/20261024_sleep_edf_sc4001_v002/
```

如果目录 `v001` 已经存在，就新建 `v002`，不要直接把旧报告覆盖掉。需要清理无价值联调数据时，可以使用平台的多选删除，但正式实验证据要先确认是否另有备份。
