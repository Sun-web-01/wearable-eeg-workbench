# 设备采集说明

## 当前支持方式

网站中的“设备采集”页面通过 BrainFlow 连接 EEG 设备。浏览器不直接访问硬件，硬件由运行平台后台的电脑连接。

| 设备配置 | 传输方式 | EEG 通道 | 当前 IMU 能力 |
|---|---|---:|---|
| BrainFlow 模拟设备 | 软件模拟 | 16 | 加速度 3 轴 + 陀螺仪 3 轴 |
| Muse 2 | 蓝牙 | 4 | 当前 BrainFlow 配置未暴露 IMU |
| Muse S | 蓝牙 | 4 | 以实际固件和 BrainFlow 版本为准 |
| OpenBCI Cyton | USB 串口 / Dongle | 8 | 加速度 3 轴 |

## 使用流程

1. 打开并配对真实设备，或选择 BrainFlow 模拟设备；
2. 点击“扫描蓝牙与串口”；
3. 选择设备类型，并填写蓝牙地址或串口；
4. 输入匿名受试者编号和状态标签；
5. 设置采集时长，开始采集；
6. 采集结束后下载 CSV、EDF 和元数据，或直接提交分析。

同一时间只允许一个采集任务，避免多个进程争用设备。

## 文件命名

统一使用接近 BIDS 习惯的名称：

```text
sub-<受试者编号>_task-<状态>_acq-<设备>_<YYYYMMDD-HHMMSS>.csv
```

例如：

```text
sub-s01_task-focused_acq-muse2_20261024-183000.csv
sub-s01_task-focused_acq-muse2_20261024-183000.edf
sub-s01_task-focused_acq-muse2_20261024-183000_metadata.json
```

说明：

- CSV 保存统一时间轴和多模态数据，供平台分析；
- EDF 保存 EEG 连续信号，适合常用 EEG 软件；
- JSON 保存设备型号、连接方式、通道、任务、参数和文件哈希；
- 采集页面不要求填写真实姓名，应使用 S01、S02 等匿名编号。

## 注意事项

- 蓝牙设备必须先打开电脑蓝牙，并让设备进入连接状态；
- 不同 BrainFlow 版本可能暴露不同传感器通道，使用前需要实际连接确认；
- 模拟设备只用于流程测试，不代表真实脑电或运动状态；
- 在 Docker 中通常无法直接访问宿主机的蓝牙或 USB 设备，真实采集应在本地主机运行；
- 正式实验仍需经过知情同意、数据匿名化和导师确认。
