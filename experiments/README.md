# 实验记录规则

每次处理必须保留以下五项：

1. 输入数据标识：数据集、受试者、session、文件 SHA-256。
2. 参数：目标采样率、带通范围、陷波、窗口长度、运动阈值。
3. 产物：`report.json`、`features.csv`、`processed.csv`。
4. 结论：可用窗口数、综合质量、异常通道、是否允许进入下游训练。
5. 变更：与上一个实验相比修改了什么，以及为什么修改。

禁止用覆盖方式保留唯一结果。建议目录：

```text
reports/runs/20261024_sleep_edf_sc4001_v001/
```

如果受试者、session 或设备信息涉及个人信息，目录中只使用内部匿名编号。
